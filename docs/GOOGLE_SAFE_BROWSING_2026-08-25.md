# Google Safe Browsing --- ложное срабатывание и успешный пересмотр

**Период:** 19--25 августа 2026\
**Статус:** решено

## Проблема

Google Safe Browsing пометил `headinspect.ru` как небезопасный сайт. В
Google Search Console в разделе **Security issues** была обнаружена
проблема:

-   тип: **Deceptive pages**;
-   Google сообщал, что некоторые страницы могут пытаться заставить
    пользователей раскрыть персональные данные или загрузить
    нежелательное ПО;
-   конкретные проблемные страницы в Search Console не были указаны:
    **Sample URLs: N/A**.

Google Transparency Report также показывал предупреждение для
`https://headinspect.ru/`, `/open-graph/` и `/meta/`. При этом
`https://api.headinspect.ru/` определялся Google Safe Browsing как
безопасный.

## Проведённая проверка

Перед отправкой запроса на пересмотр была проведена дополнительная
проверка опубликованного сайта и репозитория.

Проверено:

-   содержимое всех отслеживаемых Git-файлов в `site/`;
-   HTML и JavaScript на наличие подозрительных конструкций;
-   внешние JavaScript-подключения;
-   `iframe`, `eval()`, `atob()`, `document.write`;
-   подозрительные редиректы;
-   формы загрузки файлов;
-   поля паролей и другие формы сбора учётных данных;
-   неизвестные сторонние скрипты и файлы.

Подозрительного или вредоносного кода обнаружено не было. Формы
HeadInspect принимают URL публичного сайта исключительно для запуска
SEO-аудита.

Основные внешние обращения соответствовали штатной работе проекта:
собственный API `api.headinspect.ru`, Яндекс Метрика (`mc.yandex.ru`) и
обычные внешние ссылки проекта.

Отдельная проверка:

``` powershell
Get-ChildItem site -Recurse -Include *.html,*.js -File | Select-String -Pattern '<script[^>]+src="https?://'
```

не обнаружила прямых внешних `<script src="https://...">`.

Также был проверен полный список файлов, публикуемых из каталога `site`:

``` powershell
git ls-files site
```

Неизвестных, подозрительных или посторонних файлов обнаружено не было.

## Предполагаемая причина

Наиболее вероятная причина --- ложное срабатывание автоматической
системы Google Safe Browsing на новый сайт-аудитор.

HeadInspect позволяет пользователю ввести URL стороннего сайта,
отправить его на проверку и получить извлечённые с публичных страниц
данные и результаты анализа. Такое поведение нового домена могло быть
ошибочно классифицировано автоматическими системами как потенциально
deceptive.

Признаков фактического взлома сайта обнаружено не было.

## Request Review

25 августа 2026 года через Google Search Console был отправлен **Request
Review**.

В запросе было объяснено назначение HeadInspect, отсутствие сбора
паролей, платёжных и других чувствительных данных, отсутствие загрузок
ПО и результаты проверки исходного кода.

## Результат

**25 августа 2026 года Google одобрил пересмотр.**

Получено уведомление Google Search Console:

> Review successful for headinspect.ru

Google сообщил, что после повторной проверки его системы больше не
обнаруживают на `headinspect.ru` ссылок на вредоносные сайты или
вредоносных загрузок. Предупреждения для пользователей удаляются;
распространение изменения по системам может занять несколько часов.

## Итог

Инцидент закрыт.

-   признаков компрометации HeadInspect не обнаружено;
-   Google Security Review успешно пройден;
-   предупреждение Safe Browsing снимается;
-   специальная переделка `/open-graph/` или `/meta/` не потребовалась.

Если аналогичное предупреждение возникнет снова, этот инцидент следует
учитывать как документированный предыдущий случай вероятного false
positive для сайта-аудитора.
