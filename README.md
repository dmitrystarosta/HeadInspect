# HeadInspect — frontend prototype v1.1

Первая адаптивная версия публичного интерфейса HeadInspect.

## Что уже есть

- адаптивная главная страница;
- hero + форма ввода домена;
- демонстрация процесса аудита;
- сводка ошибок / предупреждений / OK;
- фильтры;
- таблица результатов;
- мобильное представление таблицы карточками;
- раскрытие подробностей по строке;
- ссылки «Открыть страницу / изображение»;
- блоки возможностей, процесса, FAQ;
- мобильное меню.

## Важно

Сейчас это **frontend-прототип**. Форма запускает демонстрационный сценарий, а не реальный сетевой аудит.

Это сделано намеренно: backend-краулер лучше подключить отдельным API, чтобы:
- безопасно обрабатывать внешние URL;
- защититься от SSRF;
- ограничивать параллелизм, редиректы и размеры ответов;
- показывать реальный прогресс;
- формировать XLSX.

## Как открыть

Просто откройте `index.html` в браузере.

Для корректной локальной работы можно запустить встроенный сервер Python:

```bash
python -m http.server 8080
```

Затем открыть:

```text
http://localhost:8080
```

## Следующий этап

Подключить API примерно такого уровня:

- `POST /api/audits` — создать аудит;
- `GET /api/audits/{id}` — состояние и прогресс;
- `GET /api/audits/{id}/results` — результаты;
- `GET /api/audits/{id}/report.xlsx` — Excel-отчёт.

Фронтенд уже разделён так, чтобы демонстрационный `runDemoAudit()` позже заменить реальными запросами к API.

## Обновление интерфейса результатов

Демонстрационный аудит теперь имитирует 487 страниц:
- 8 ошибок;
- 27 предупреждений;
- 452 страницы без замечаний.

Результаты выводятся компактными строками, а не крупными мобильными карточками.
По умолчанию показываются только проблемы. Строка раскрывается по нажатию.
Большие выборки (OK / Все) выводятся порциями по 50 строк через кнопку «Показать ещё».
